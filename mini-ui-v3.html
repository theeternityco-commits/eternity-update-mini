qr code edit

Save the QR image from your shop's bank app and upload it once — the kiosk decodes it and regenerates a QR with the amount embedded for every order. Customers scan and the amount fills itself in; no typing mistakes. Money still lands in the shop account directly. If not uploaded, the PromptPay number above is used (amount embedded too).

Give each kiosk in the shop a different number — each kiosk's charge differs by a few satang (discounted, max 99 st.) so money-in notifications never cross kiosks. Single kiosk = off.

When on, the QR opens theeternitythailand.com where customers choose color / B&W film / GIF (the GIF records the countdown before each shot, up to 3s/shot). The kiosk code is set automatically, and if the hub note fails it falls back to the direct file link.

Install your shop's bank app on this kiosk (K SHOP / SCB) and grant notification access — when a "money in" notification matches the price, the screen advances automatically.
