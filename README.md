# eternity-update-mini

ไฟล์อัปเดตของตู้ Mini Photobooth (แยกจาก eternity-update ของตู้ Receipt)

- mini-vc2.apk = versionCode 2 (13 ต.ค. 2569) — ชดเชยขอบที่เครื่องตัด
- mini-vc3.apk = versionCode 3 (13 ต.ค. 2569) — รูปอยู่ระหว่างเส้นประบน-ล่าง แถบรูเจาะขาว
- mini-vc4.apk = versionCode 4 (14 ต.ค. 2569) — ปรับตามใบพิมพ์จริง: ย่อแนวตั้งเพิ่ม 1% ดันรูปขึ้น 0.75 มม.
- mini-vc5.apk = versionCode 5 (15 ต.ค. 2569) — รูปใหญ่กว่าช่องเส้นประ ~0.5 มม./ปลาย ไม่มีช่องขาว
- mini-vc6.apk = versionCode 6 (19 ต.ค. 2569) — วิดีโอหน้าแรกย่อ 1200×1920 + poster/preload: หน้าแรกขึ้นทันที (ไฟล์เล็กลง 4 MB)
- mini-vc7.apk = versionCode 7 (19 ต.ค. 2569) — เลข 6 + ไฟล์แถมของ QR (ขาวดำ/GIF) แยกเพดานเวลา ไม่ทิ้งทั้งคู่เมื่อตัวหนึ่งช้า
